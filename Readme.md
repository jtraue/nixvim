## Plugins

| Name           | Description                                    |
| -------------- | ---------------------------------------------- |
| [bufferline.nix](https://github.com/akinsho/bufferline.nvim) | Tab-like interface for easy buffer navigation. |
| [lualine.nix](https://github.com/nvim-lualine/lualine.nvim) | A blazing fast and easy to configure Neovim statusline. | 
| [git.nix](https://github.com/lewis6991/gitsigns.nvim) | Super fast git decorations. |
| [autopairs.nix](https://github.com/windwp/nvim-autopairs) | A super powerful autopair plugin for Neovim that supports multiple characters. | 
| [cmp.nix](https://github.com/hrsh7th/nvim-cmp) | A completion engine plugin. |
| [tree-sitter.nix](https://github.com/nvim-treesitter/nvim-treesitter) | Use the incremental parser tree-sitter for neovim functionality such as highlighting. |
| [telescope](https://github.com/nvim-telescope/telescope.nvim)| Fuzzy finder over lists. |

| [which-key.nix](https://github.com/folke/which-key.nvim) | Show configured keymappings. |

### Bufferline

* left click on a buffer to switch to it
* right click on a buffer name to close it

### Gitsigns

* `Gitsigns toggle_current_line_blame` show/hide blame

### which-key

* Show a popup with possible key bindings. Example: hit leader (Space) and wait for a short moment.
